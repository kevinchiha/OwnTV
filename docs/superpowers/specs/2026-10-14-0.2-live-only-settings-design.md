# 0.2-live-only-settings: Settings and More fit a live-TV-only app

## Goal

A KevBox Live member who opens Settings or More sees only settings and pages that do something in a live-TV-only app. The preview box always plays with sound, and nothing in the app can break the box-to-full-screen grow, schedule a recording nobody can watch, or start Multiview.

## Scope

- **Hide list.** A new `app/src/main/java/tv/own/owntv/kevbox/settings/LiveOnlySettings.kt` holds the hidden row keys and the fixed values. Upstream files get small filter hooks where root rows, Video player rows, search entries, Quick pins and More › Settings cards are built (`features/shell/components/SettingsScreen.kt`, `features/settings/VideoPlayerSettingsScreen.kt`, `features/more/MorePages.kt`).
- **Settings rows.** Hide the dead and movie-only rows, move "Android TV home" and Customize, rename the catch-up rows, fix App startup's label, and hide the per-playlist catch-up row when only one playlist exists.
- **Fixed values.** Preview sound is always on, the accent and focus colour are always KevBox blue (#6FB0FF), Live TV always remembers the category but not the channel, and a 0 preview width no longer blocks Live preview.
- **Player and guide.** No Record actions, no Multiview button, no Auto frame rate popup. CH+/CH− jump N channels in the guide grid. Remote shortcut actions that only reached removed screens go.
- **Guide sources.** No "Fill from playlist". The automatic guide is locked against delete and edit. Guides refresh every 24 h by default, and the old guide goes when the admin changes a playlist's server.
- **More screen.** History and Favorites list live channels only, with a simple Clear history. About gets KevBox wording and a fixed languages button, and Language loses "Help translate".
- **Previews.** The Appearance preview (`features/settings/SettingsLivePreview.kt`) and the Glass & background preview (`GlassBackgroundPreview` in `features/shell/components/GlassEffectPage.kt`) draw a mini guide instead of the old Home screen.
- **Records.** `// KevBox:` comments, UPSTREAM-SYNC.md rows, tests.

Paths without a prefix are under `app/src/main/java/tv/own/owntv/`.

## Acceptance criteria

### Hide list and search

- **AC-1** `kevbox/settings/LiveOnlySettings.kt` exists and is the only place that lists the row keys KevBox hides and the values KevBox fixes. Its hidden-key set is exactly the keys AC-2 and AC-3 name plus `quick_preview_sound` (AC-9, AC-13). Its fixed values are the ones AC-13 to AC-15 and AC-38 state. A unit test asserts that exact hidden-key set and those fixed values.
- **AC-2** The Settings root no longer shows:
  - Live TV layout (`live_layout`), Live TV opens in (`live_opens_in`), Movies & Series layout (`vod_layout`)
  - Panel widths (`tab_PANEL_WIDTH`), Long-press menus (`tab_CONTENT_MENUS`), Browsing & lists (`browsing_lists`)
  - Home screen (`tab_HOME`), Metadata (`tab_METADATA`), OpenSubtitles (`tab_OPEN_SUBTITLES`)
  - Accent color (`accent`), Focus highlight (`focus_highlight`)

  Rows that are not listed keep their place and behaviour.
- **AC-3** Video player settings, and every Settings group built from its catalogue (`VIDEO_QUICK_ROWS`), no longer show:
  - Live TV player (`vp_live_engine`) and its per-playlist row (`vp_live_engine_sources`)
  - Movies & Series player (`vp_vod_engine`) and its per-playlist row (`vp_vod_engine_sources`)
  - Reset saved player choices (`vp_reset_pins`), Resume playback (`vp_resume`)
  - Pause during the display switch (`vp_afr_pause`), Match resolution (`vp_afr_resolution`)
  - Multiview (`vp_multiview`), Most tiles (`vp_multiview_tiles`), Preview audio (`vp_preview_audio`)

  These stay: Auto frame rate (`vp_afr`), Reset saved live TV player choices (`vp_reset_live_pins`), Forget learned stream fixes (`vp_forget_fixes`).
- **AC-4** The four recording settings (Keep one stream free for watching, Record what I'm watching, Start early, Keep going after the end; drawn by `RecordingSettingsRows` in `features/settings/RecordingSettingsScreen.kt`) no longer appear in Settings. The "Watching & recording" group (`settings_group_watching_recording`) is named "Watching", its "Controls & resume" heading (`settings_vp_cat_controls_resume`) reads "Controls & catch-up", and its "Multiview & mini-player" heading (`settings_vp_cat_multiview`) reads "Mini-player", in English and French.
- **AC-5** The External player dialog shows only its Live TV switch. Its Movies and Series switches are gone.
- **AC-6** The Navigation popup (`features/settings/NavigationSettingsPopup.kt`) no longer shows the menu-items mode or the per-section menu switches. Its style, size, length, widen-on-focus and hide-after controls stay, under the same conditions as today.
- **AC-7** Customize categories & items shows only its Live TV tab. Its row sits in the Live TV settings group, and the Content & metadata group no longer appears anywhere: not on the root, not on More › Settings, not in search.
- **AC-8** "Android TV home" and its "Refresh now" action appear in the App group and behave as before (default on). The Home screen page (`SettingsTab.HOME`) cannot be reached.
- **AC-9** On an install whose stored Quick pins are Core's out-of-the-box list (`DEFAULT_QUICK_PINNED`: `quick_live_preview`, `quick_preview_sound`, `quick_channel_numbers`, `quick_hdr`, `quick_autoplay`, `quick_check_update`), Quick shows exactly Live preview, Channel numbers and Check for update, in that order. A hidden row never shows in Quick, even if an install pinned it earlier.
- **AC-10** Settings search returns no entry for any row or page hidden by AC-2 to AC-8. Searching "TMDB", "OpenSubtitles", "Panel", "Multiview", "Record", "Accent", "Resume" or "Preview audio" finds nothing hidden.
- **AC-11** On More › Settings, no card description names a row or page that AC-2 to AC-8 hide: none mentions TMDB, Home, panels, accent, resume, multiview or recording. Each card's row count equals the number of rows its group shows, and the counts come from the same data as the rows, not from typed numbers.
- **AC-12** `SettingsSearchCoverageTest` (`app/src/test/java/tv/own/owntv/features/shell/SettingsSearchCoverageTest.kt`) passes and reads the hidden keys from `LiveOnlySettings`, so a row hidden there needs no search entry and a visible row still does.

### Fixed values

- **AC-13** The preview box always plays with sound: after OK on a channel, and after a focus move while Live preview is on. This holds on an install whose stored "Preview audio" is off, and nothing in the app mutes the box any more. Back from full screen to the grid keeps the sound on, as today.
- **AC-14** The accent colour is #6FB0FF and the focus outline follows it on every screen, whatever accent or highlight colour an install has stored.
- **AC-15** Live TV reopens on the category the member left (remember category = on) and starts that category at the top (remember channel = off), whatever an install has stored.
- **AC-16** Turning Live preview on always works. A stored Live preview panel width of 0 no longer refuses it or opens the "panel hidden" dialog (`LivePreviewPanelHiddenDialog`).

### Settings wording and small fixes

- **AC-17** These rows keep their behaviour and get catch-up wording in their title and description: Auto-play next episode (`vp_autoplay`) becomes "Catch-up: play the next programme"; Seek step (`vp_seek_step`), Film buffer (`vp_vod_buffer`), Network timeout (`vp_vod_timeout`) and Reconnect attempts (`vp_vod_reconnects`) say "catch-up" in place of movie, episode or film. The new text exists in English and French; every other app language shows the English text.
- **AC-18** App startup's first option reads "Live TV" instead of "Home", in the dialog, the row chip and search. The message shown when the chosen startup channel is missing (`settings_startup_channel_unavailable`) says Live TV opened, not Home.
- **AC-19** "Catch-up time zone per playlist" (`catchup_sources`) shows only when the active profile has two or more playlists (the list its dialog offers). Today it shows with one.
- **AC-20** The Auto frame rate suggestion popup never appears in full screen, on any channel or frame rate. The Auto frame rate row stays and defaults to off.

### Player and guide

- **AC-21** No path can schedule a recording: the guide's programme menu has no Record or Cancel recording action, and the full-screen controls have no Record button.
- **AC-22** The full-screen controls have no Multiview button, and Multiview cannot start, even on an install whose stored Multiview setting is on.
- **AC-23** Remote shortcuts no longer offer Open Home, Open Movies, Open Series, Open Downloads or Open TV Guide (`RemoteShortcutAction` `OPEN_HOME`, `OPEN_MOVIES`, `OPEN_SERIES`, `OPEN_DOWNLOADS`, `OPEN_GUIDE`). A button already bound to one of them opens Live TV. The Downloads screen cannot be reached from any button.
- **AC-24** In the Live TV guide grid, CH+ moves the focused channel toward the first channel by the Remote shortcuts CH+ skip count (`chNavUpSkip`), and CH− moves it toward the last channel by the CH− skip count (`chNavDownSkip`); both default to 10. The move stops at the first or last channel without wrapping. Full screen still moves one channel per press.

### Guide sources

- **AC-25** The EPG sources page and its add form have no "Fill from playlist" action.
- **AC-26** The automatic guide (a feed whose URL is one of the member's playlist's own guide URLs, as `kevbox/epg/GuideFeeds.kt` adds it) shows as managed: Delete and URL edit are not offered for it, and its refresh interval stays editable. Guides the member added by hand can still be edited and deleted.
- **AC-27** A guide added by hand defaults to a 24-hour refresh (today the add form starts on Off). A newly added automatic guide is set to 24 hours (today `GuideFeeds.kt` sets 12 hours).
- **AC-28** When the admin changes a playlist's server URL, the next playlist sync on the TV (which updates the source in place) removes the guide feed for the old server and adds the one for the new server. No stale feed keeps downloading.

### More screen

- **AC-29** History lists live channels only. It has no Live TV / Movies / Series tabs, opens on the channel list (also on a new install with nothing watched), and never shows a movie or series entry stored before this phase.
- **AC-30** Clear history asks one yes/no question and clears live history. It offers no Movies, Series or All choice.
- **AC-31** Favorites lists channels only: no All / Live TV / Movies / Series filter and no Movies & Series poster row. Its count counts channels only, and its empty text mentions channels only.
- **AC-32** About reads "KevBox Live plays the live TV channels in your KevBox subscription, with a full programme guide, replays and favourites. Your playlist is set up for you; contact KevBox if a channel is missing." in English, and a French translation of the same text in French. Its languages button opens Settings on the App group with the Language row focused (today it opens Sound & subtitles).
- **AC-33** The Language page shows no "Help translate" panel and no link to upstream's translation project.

### Previews

- **AC-34** The preview at the top of the Appearance group draws a mini Live TV guide (menu, category column, channel rows with programme bars, top video box) in the current theme, glass and font settings. Its rows are the first channels of the member's current Live TV category, with their logos and current programmes; with no synced channels yet it draws a fixed sample instead. It no longer starts HomeViewModel or draws a trending movie.
- **AC-35** The Glass & background page's preview draws the same mini guide and fetches no movie frame. The black video box is gone.

### Records and checks

- **AC-36** Every changed upstream line carries a `// KevBox:` comment saying what changed and why. UPSTREAM-SYNC.md's "Changed upstream files" table has a row for every upstream file this phase changes, each with a grep proof command; a file already in the table gets the new greps added to its row.
- **AC-37** `./gradlew testStandardDebugUnitTest` passes with new tests for the hide list (AC-1, AC-12), the CH+/CH− step and clamp (AC-24), and the feed swap on a server change (AC-28). `./gradlew assembleStandardRelease` builds.
- **AC-38** The stored values behind the hidden engine rows are ignored. Live full screen starts on ExoPlayer with mpv as the automatic fallback, and catch-up starts on mpv with ExoPlayer as the automatic fallback, even on an install that stored a Live TV player of mpv or a Movies & Series player in an "only" mode, globally or per playlist. A per-channel choice made with the full-screen engine button still applies, and "Reset saved live TV player choices" still clears it.
- **AC-39** The last build task installs the release build on Kevin's TV with `tools/kevbox/tv-install.sh` (new in this phase, committed), built with the version the TV already runs (read from the TV with `dumpsys package`) and signed with the KevBox TV key, so `adb install -r` keeps his data. It then recompiles the app over adb (`cmd package compile -m speed-profile -f tv.kevbox.live`), force-stops it and waits for Kevin's check. If the TV does not answer, the task stops and asks Kevin to wake it. The phase does not close on a red check without his ruling.

## Non-goals

- **No Core fork.** Every change stays in the app layer. A Core fork doubles every upstream merge.
- **No deletion of old movie, series or recording data on members' TVs.** It stays stored and never shows. A one-time delete on members' TVs is a risk with no visible payoff.
- **No recordings viewer.** Kevin chose to hide recording completely.
- **No Maximum video quality change.** It stays at no limit, so 4K TVs get the best picture without anyone touching it.
- **No new look.** Theme, Glass, Ambient glow, Fonts, Popup size, UI zoom, Animations and Weather stay as they are.
- **No translations beyond English and French for new or renamed text.** Every other app language shows the English text. `kevbox_strings.xml` is English only today, so the French text needs a new `values-fr/kevbox_strings.xml`.
- **No removal of Multiview, recording or VOD code.** It becomes unreachable; deleting upstream code makes every upstream merge conflict.
- **No release.** Publishing 5.1.0.8 waits for Kevin's go after he tries the build on his TV.
- **No kevbox.dev change.** The feed swap in AC-28 happens on the TV.

## Decisions

- Approach B: one KevBox list (`LiveOnlySettings.kt`) plus small filter hooks in upstream files. Rejected A (delete in place: about 60 scattered edits that conflict on upstream updates) and C (own KevBox Settings screen: rebuilds focus, search and Quick, and new upstream settings never appear).
- Recording: hide completely, settings and guide actions. Rejected adding a Recordings page under More: more work, and recordings fill TVs with little storage.
- Preview sound: always on, switch removed. Rejected on-by-default with the switch, and keeping it off.
- Live TV player picker and its per-playlist row: hidden. The automatic ExoPlayer-first fallback stays. Rejected keeping the picker (switching to mpv breaks the grow) and forcing ExoPlayer only (a channel ExoPlayer can't open would just fail).
- Full-screen engine switch button: kept as a rescue for a channel that won't play. "Reset saved live TV player choices" stays to undo it.
- Multiview: hidden, including the full-screen button. Rejected keeping it off by default: too heavy for 2.4 GB TVs.
- Maximum video quality: stays at no limit. Rejected a 1080p default.
- Auto frame rate: kept, off by default; it works on live full screen on ExoPlayer (`OwnTVShell.kt:1079`). Its two movie-only sub-rows are hidden and the suggestion popup is removed. Rejected hiding it (members with 50 Hz-capable TVs lose smoother motion) and keeping the popup (it asks a technical question mid-watch, even on TVs that can't switch).
- Movie-only player rows: hidden. Nothing reads them in a live-only app, and hiding keeps the stored values.
- Catch-up rows with movie names: kept and renamed. Rejected keeping the old names and hiding them.
- Quick: Live preview, Channel numbers, Check for update. Rejected Live preview + Channel numbers only, and leaving Quick as it is.
- Dead layout rows: all hidden. Rejected keeping them.
- Home screen page: hidden; "Android TV home" moves to App and stays on. Rejected defaulting it off and hiding it too.
- Content & metadata: Metadata and OpenSubtitles hidden; Customize keeps only its Live tab and moves to the Live TV group, and the empty group goes. Rejected keeping a one-row group.
- Browsing & lists: the whole page hidden; remember category fixed on, remember channel fixed off. Kevin's own call, in place of the options offered.
- Remote shortcuts: remove the 5 dead actions; CH+/CH− jump N channels in the grid. Rejected hiding the skip setting and hiding the whole page.
- Guide sources: hide "Fill from playlist", lock the automatic guide, 24-hour refresh by default for both kinds. Kevin's call: rejected 12 h.
- Accent: hidden, always KevBox blue. Rejected adding a KevBox preset.
- Theme: kept. Focus highlight: hidden, always KevBox blue. Rejected hiding Theme too, and keeping Focus highlight without its thickness slider.
- Rest of Appearance: kept; both previews redrawn as a mini guide. Rejected removing the previews and hiding Glass and Ambient glow.
- App startup: "Home" renamed "Live TV" and kept as the default. Rejected defaulting to Last channel.
- History and Favorites: live channels only; old movie entries stay stored but never show. Rejected a one-time delete of old entries.
- About and Language: reword About, fix the languages button, hide "Help translate". Rejected limiting Language to English and French.
- Small fixes all in: old guide removed on a server change, the per-playlist catch-up row hidden with one playlist, the startup message, the More › Settings card descriptions and counts.
- Fixed values are read through `LiveOnlySettings` rather than written into storage, so existing installs follow them at once and no one-time migration is needed.
- Base branch is `kevbox-live` (the fork's long-lived branch, as in 0.1), not `origin/main` (upstream's).
- Size: 39 criteria, within the cap (37 at the size check; grill round 1 added AC-38 and AC-39)
- Grill round 1: no member has installed KevBox Live yet; only Kevin's own TV runs it. So nothing handles recordings already scheduled, and no one-time move of existing 12 h automatic guides to 24 h. Rejected cancelling or freezing scheduled recordings, and a one-time refresh migration: no install needs them.
- Grill round 1: the stored values behind the hidden engine rows are ignored (AC-38). Live starts on ExoPlayer with mpv fallback; catch-up starts on mpv with ExoPlayer fallback. Per-channel choices made with the full-screen engine button still count. Rejected keeping stored values: a TV could end up stuck on a choice nobody can see or undo. Checked in Core's `player-core/.../player/OwnTVPlayer.kt`: catch-up always starts on mpv (line 2990), and the Movies & Series setting decides whether it may fall back to ExoPlayer (lines 3025-3036).
- Grill round 1: the renamed catch-up rows (AC-17) get English and French text; every other language shows the English text. Rejected English only (a French member sees English rows among French ones) and keeping the old translated movie wording.
- Grill round 2: the mini-guide previews show the member's real first channels of the current category, with a fixed sample before the first sync (AC-34). Rejected a fixed sample always: the preview should look like the member's own Live TV.
- Grill round 2: About text as written in AC-32, English and French. Replaces upstream's "bring your own sources".
- Grill round 2: "Watching & recording" becomes "Watching", with headings "Controls & catch-up" and "Mini-player" (AC-4), so no heading names a removed feature.
- Grill round 1: the build's last task installs the build on Kevin's TV with `/tmp/kevbox-tv/tvbuild.sh` and waits for his check (AC-39), as 0.1 did. Rejected relying on unit tests alone: most of this phase is what shows on screen.
- Grill: run to an empty frontier
- Checked: AC-38 needs no Core fork and no storage write: the app builds Core's `LiveTuneController` host and passes the source in `features/live/LiveViewModel.kt`, and its catch-up `player.play(...)` call can pass `vodEngineOverride`, so the app can supply the fixed engine order itself.
- auto-resolved: the Non-goals said "no translations beyond English", which contradicts AC-4, AC-17 and AC-32 and grill round 1 (English and French). Non-goals now say English and French, rejected English only, because the grill decision is the later and more specific one.
- auto-resolved: "an install that never edited its Quick pins" (AC-9) means the stored list equals Core's six defaults, rejected writing a KevBox pin list at first run, because Core returns its defaults when nothing is stored, so the app cannot tell an unedited list apart, and a first-run write would never reach Kevin's TV, which is already set up.
- auto-resolved: `quick_preview_sound` joins the hidden keys (AC-1, AC-9), rejected leaving it pinnable, because AC-13 says nothing in the app mutes the box and that Quick row is a mute switch. `quick_hdr` and `quick_autoplay` stay pinnable but are not in the default three.
- auto-resolved: AC-11 now says no card names a hidden row and adds "panels" and "accent" to its word list, rejected keeping the five-word list, because the Layout card reads "Navigation, panels, Home, menus" and the Appearance card "Theme, accent, glass, text", which still name rows AC-2 hides.
- auto-resolved: "two or more playlists" (AC-19) counts the active profile's playlists, the ones the row's dialog lists, rejected the member's KevBox playlist count, because a hidden line is not linked to the profile and would make the dialog list one playlist.
- auto-resolved: UPSTREAM-SYNC.md gets a row per changed upstream file (AC-36), rejected a row per change area, because the file's existing table is one row per file with a grep proof each.
- auto-resolved: the fixed accent in `LiveOnlySettings` reuses `LiveOnly.ACCENT_HEX` (`kevbox/live/LiveOnly.kt`, which `kevbox/ui/AutoSetup.kt` already writes at first run), rejected a second #6FB0FF literal, because AC-1 wants one place per fixed value.
- auto-resolved: /tmp/kevbox-tv/tvbuild.sh was lost in a PC restart; the phase adds tools/kevbox/tv-install.sh (AC-39), which builds and signs the way release.sh does and installs over adb.
- auto-resolved: AC-35's preview is `GlassBackgroundPreview` in `GlassEffectPage.kt`, not `GlassEffectPreview` in `SettingsScreen.kt`, because the latter sits in `GlassEffectContentScreen`, which nothing calls.
