### Notes

1. **Two rows, not one ×2.** The second failure used a different channel (E2E News Three), so the
   TV queue and the server kept two rows of `repeat_count` 1 each; the check counts across rows and
   opened on the second, as AC-15 says for two `stream_lost` rows. Both rows say `account_status
   unreachable`: the account check after the 403 got no answer it could read. That is not one of
   the blocking statuses, so the failure stayed a counting one and the advice came from the proxy
   rule. The cron call before moving the time ran 10 s after the second row arrived, not at 14
   minutes; it shows only that a fresh pair opens nothing.
2. **No watching-again message to try.** With Telegram unset, incident 1 never got `alerted_at`, so
   its clearing had no message to send (AC-22) and the body says `telegram: "ok"`. Only a run that
   has a message to send reports `"unconfigured"`, as checks (b) and (c) show.
3. **The brief's network commands do not cut this emulator.** `kevbox_tv` reaches the network over
   Ethernet (`eth0`, `Active default network: 100 … Ethernet CONNECTED`). `svc wifi disable` changed
   nothing (`ping 10.0.2.2` still answered), `svc data disable` failed with `Can't find service:
   phone`, and a first try with them sent the note at once (`last_play_received_at 21:29:56`). There
   is no `svc ethernet`, and `adb root` does not work on this image. I used Android's per-app
   firewall instead: `cmd connectivity set-chain3-enabled true` and `cmd connectivity
   set-package-networking-enabled false tv.kevbox.live` (`chain:enabled`, `tv.kevbox.live:deny`),
   undone with `… true tv.kevbox.live` and `set-chain3-enabled false` (`chain:disabled`). That cuts
   every connection the app makes, which is what AC-5 needs; other apps kept their network. I
   pressed Home before giving the network back, so the arrival could only come from the foreground
   retry and not from a new 30-second run. The box played on from its buffer for about 40 s and then
   showed a spinner; the 30-second mark came first.
4. **Sign-in keys.** As in 0.3: OK on a field opens the keyboard, `input text` types, Enter commits,
   ▼ moves on. From the guide's start focus, ▶ twice reaches the channel list; OK on a channel
   previews it, and OK on the previewed channel opens full screen.
