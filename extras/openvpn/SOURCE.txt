OpenVPN engine embedded in KevBox Live: source offer
=====================================================

built from the exact source below, with the two patches named below applied. It is distributed
under the GNU GPL version 2 with the additional terms in LICENSE-ics-openvpn.txt (copied unchanged
from doc/LICENSE.txt at the same tag). The OpenVPN 2.x core, OpenSSL, LZO and LZ4 inside it carry
their own licences, listed in the engine's assets/full_licenses.html.

OpenVPN 3, asio and mbed TLS are not built.

Patches (in this repo, applied in this order by the build script):
  tools/kevbox/openvpn/0001-engine-as-library.patch
      Builds the "main" module as an Android library: library plugin, no application id, version
      or signing, no Application class on <application>, no android:process on any component,
      only arm64-v8a, armeabi-v7a and x86_64, the skeleton flavour told to CMake by an argument
      (-DOVPN_SKELETON=ON) and to NativeUtils (whose FLAVOR is "skeletonOvpn2" in a library, so it
      no longer loads the absent speed-test library), no OpenVPN 3 SWIG step, version-catalog
      names written inline.
  tools/kevbox/openvpn/0002-no-tv-toast-no-keepalive-job.patch
      OpenVPNService shows no status toasts on a TV and schedules no keep-alive job.

Build command (from the root of this repo, on Linux with JDK 17+, the Android SDK, NDK
29.0.14206865 and CMake 3.22.1):
  bash tools/kevbox/openvpn/build-engine.sh
It clones the tag, checks the commit, fetches the four submodules above, applies the patches and
runs, inside the engine checkout:
  ./gradlew --no-daemon clean :main:assembleSkeletonOvpn2Release
then copies main/build/outputs/aar/main-skeleton-ovpn2-release.aar here under the name above.
